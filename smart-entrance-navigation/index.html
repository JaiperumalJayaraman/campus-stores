TECHNICAL DECISION RECORD

How entrance recommendations work

Each candidate entrance passes through three checks: access eligibility → approach path → internal destination path. The system runs Dijkstra on two weighted graphs and selects the lowest-cost valid route.

1. Filter gates by role & mode2. Calculate shortest paths3. Rank and explain alternatives

The route weights and fictional access rules are for demonstration only. Production would need verified entrance locations, mobility-access data, real-time restrictions, privacy controls, and user research.
